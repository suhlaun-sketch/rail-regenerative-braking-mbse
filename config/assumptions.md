# 天津地铁电机选型工程假设

以下参数仅用于比赛阶段的同口径仿真对比，不代表天津地铁或厂家公开实测值：4M2T/16台电机配置、60 kg/人、14 t轴重设计包络、2800 mm车宽、840 mm轮径、7.37齿轮比、1500 V直流供电、Davis阻力、牵引/再生效率、逆变器限流、DC-link上下限、超级电容容量与接受功率、坡起35‰、控制器及制动混合参数。四候选使用完全相同的这些参数。

公开目录直接支撑6辆B型车、80/90 km/h、Tc/M车辆长度、自重范围和AW载客量；GB/T 7928-2025公开页面只支撑标准身份与现行状态，因此未把无法从公开正文复核的尺寸值伪装成标准条款。
