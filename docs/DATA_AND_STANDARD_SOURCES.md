# 来源与外部标准

正式 SysML、需求、仿真模型和实验结果来源于本项目原工作目录；本仓库按 SHA-256 核对副本。SSI Transformer 源码为第三方 [Standard-System-Interface](https://github.com/mvd-oulu/Standard-System-Interface)，仓库内保留原 MIT LICENSE/CITATION；其论文示例与本项目冻结结果不是同一批资产。SysON 由 [Eclipse SysON](https://www.eclipse.org/syson/) 提供；FMI、SSP、SysML 标准文件应从各标准组织官方渠道取得。MATLAB/Simulink 属于 MathWorks，另行安装授权。

大文件通过同一私有仓库的 Git LFS 分发；资产清单逐项记录 `repository-lfs` 或 `repository-git`。没有以公开下载链接替代私有访问控制。
