# 牵引电机代理模型假设

- 模型类型：parameterized surrogate traction motor model based on published nameplate data。
- 低速区使用公开起动转矩上限；达到 `P/T` 对应基速后使用恒功率包络；超过公开最高转速时输出转矩为零并触发速度违约判据。
- 电流由公开额定电流和转矩/额定转矩比例构造，仅作为横向热负荷代理，不代表厂家实测电流 MAP。
- 牵引效率 92%、再生效率 88%、齿轮效率 97% 为统一工程假设。
- 精确齿轮比、控制器参数、逆变器限流、DC-link 动态和超级电容接受能力没有天津线路公开定值，采用固定统一参数，四候选保持一致。
- 候选之间只替换电机铭牌参数。车辆、线路、指令、传动、逆变器、储能和数值步长均保持不变。
